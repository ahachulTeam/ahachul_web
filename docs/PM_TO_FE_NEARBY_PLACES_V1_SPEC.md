# PM -> FE 기능명세서: 주변 간단 식사/편의시설 추천 V1

- 작성일: 2026-02-24
- 기준 문서: `ahachul_data/docs/PM_SUBWAY_PUBLIC_DATA_DEEP_RESEARCH_2026-02-23.md`
- 목표: 홈 역 카드에서 주변 요깃거리/편의시설 정보를 바로 확인

## 1. 구현 범위
1. 홈 `TrainRealTimes` 카드에 `주변 간단 식사/편의시설` 섹션 추가
2. BE 신규 API `GET /v2/stations/nearby-places` 연동
3. 추천 항목 기본 3건 노출(이름/카테고리/도보분/영문메뉴)
4. 현재 선택 역/노선 기준 조회

## 2. 표시 규칙
1. 로딩: `주변 장소 정보를 불러오는 중...`
2. 성공: `이름 · 카테고리 · 도보 n분`
3. 실패/없음: `주변 추천 정보 준비 중입니다.`
4. 영문메뉴 가능 시 `영문메뉴` 배지 노출

## 3. 요청 규칙
1. `stationId`, `subwayLineId` 필수
2. `limit=3` 기본 사용

## 4. 테스트 요구사항
1. 요청 단위 테스트 추가(`subway.nearby-places.v2.test.ts`)
2. 경로/파라미터 검증
3. UI 키워드 스캔 가능 문구 포함

## 5. 완료 조건 (DoD)
1. 홈 카드에 섹션 노출
2. API 오류 시 UI 깨짐 없음
3. 테스트 PASS 증적 포함
4. 문서/코드 주석은 한국어 유지
