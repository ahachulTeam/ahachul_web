# PM -> FE 핸드오프: 홈 UX 2~3뎁스 개편 (2026-02-26)

## 1. 미흡한 부분

- 홈에서 실행 액션까지 처리되어 과밀 UX가 발생함.
- 기능 진입 경로가 통일되지 않아 학습 비용이 높음.

## 2. 개선 포인트

- 홈은 “요약 + 이동” 역할만 수행.
- 핵심 실행은 허브(2depth), 상세/작성은 3depth에서 수행.

## 3. FE 구현 요구사항

1. 홈 공통

- `투표 라운지` 버튼을 상단 CTA로 노출
- `핵심 기능 바로가기`를 카드형으로 노출
  - 투표 라운지
  - 커뮤니티 허브
  - 유실물 허브
  - 민원 허브

2. 투표 플로우

- 홈에서는 투표 결과 요약만 표시하고 직접 투표 버튼 제거
- 2depth `투표 라운지`에서 실제 투표 수행
- 3depth 상세는 댓글 작성/정렬/좋아요 유지

3. 동선

- 상세/게시판 상단 복귀 버튼은 홈이 아니라 라운지로 우선 복귀

## 4. 검증 체크리스트

- [ ] 홈에서 클릭 한 번으로 투표가 완료되지 않는지
- [ ] 라운지에서 투표/댓글 미리보기가 동작하는지
- [ ] 상세에서 댓글 작성/좋아요가 기존과 동일하게 동작하는지
- [ ] one-app/vite가 같은 IA 구조를 가지는지

## 5. 검증 결과

- one-app/vite 공통으로 위 요구사항 충족 확인
- FE 게이트(type/lint/test) 전체 통과
