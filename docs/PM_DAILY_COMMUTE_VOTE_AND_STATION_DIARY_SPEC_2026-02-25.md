# 홈 일일 투표 + 역 일기 기능 명세 (2026-02-25)

## 1. 미흡한 부분

- 홈에서 출퇴근/등하교 체감을 실시간으로 공유하는 기능이 없다.
- 즐겨찾기 역/라벨(직장, 학교 등)을 활용한 개인화된 공감 UX가 부족하다.
- 댓글은 텍스트 중심이라 이미지/GIF 기반 반응 문화(밈, 현장 사진 공유)를 담기 어렵다.

## 2. 개선 포인트

- 매일 새로 열리는 “오늘 n호선 출근/퇴근(또는 등교/하교) 어땠나요?” 투표를 홈에 노출한다.
- 즐겨찾기 라벨 기반으로 주 투표를 결정한다.
- 직장 라벨 우선: 출근/퇴근.
- 학생 라벨 우선: 등교/하교.
- 학생도 출퇴근 투표는 보조 투표로 노출한다.
- 오늘의 주 투표 완료 시 “오늘의 xx역은 어떠셨나요?” 역 일기 섹션을 unlock한다.
- 투표 댓글은 텍스트 + 이미지 URL 목록(GIF 포함)으로 확장한다.
- 댓글 좋아요 및 정렬(최신/인기)을 지원한다.

## 3. 개발 진행

### 3.1 정책

- 시간대 정책(Asia/Seoul):
- `05:00~14:59`: 등교/출근 문구
- `15:00~23:59`: 하교/퇴근 문구
- `00:00~04:59`: 당일 새벽은 `05:00~14:59` 정책과 동일하게 취급
- 일일 단위 리셋: `poll_date(yyyy-MM-dd)` 기준으로 매일 별도 poll 생성.

### 3.2 BE 범위

- 신규 API
- `GET /v2/daily-votes/today`
- `POST /v2/daily-votes/{pollId}/votes`
- `GET /v2/daily-votes/{pollId}/comments?sort=latest|popular`
- `POST /v2/daily-votes/{pollId}/comments`
- `POST /v2/daily-votes/comments/{commentId}/likes`
- `DELETE /v2/daily-votes/comments/{commentId}/likes`
- 핵심 로직
- 회원 즐겨찾기 역/라벨 기반으로 오늘의 주 투표/보조 투표 생성 또는 조회
- 주 투표 1인 1표 보장
- 주 투표 참여 여부에 따라 역 일기 노출 여부 계산
- 투표 댓글 이미지 URL 배열 저장/조회
- DB
- poll, vote, poll_comment, poll_comment_like 테이블 추가
- 공통 댓글 DTO는 `imageUrls`를 포함하도록 확장(기존 게시글 댓글도 호환 유지)

### 3.3 FE 범위

- 홈 화면
- 주 투표 카드 + 보조 투표 카드 노출
- 투표 완료 상태/미완료 상태 구분
- 역 일기 unlock 상태 표시
- 투표 상세
- 옵션 선택, 투표 제출, 집계 결과 노출
- 댓글 리스트(최신/인기), 댓글 작성, 이미지 URL 추가/삭제
- 이미지 URL 유효성 안내 및 실패 메시지 제공
- 앱 범위
- `one-app`과 `vite` 동등 기능으로 제공

## 4. 완료조건/예외정책

- 완료조건
- 홈에서 사용자별 주 투표가 시간대/라벨 정책에 맞춰 표시된다.
- 투표 후 즉시 집계 결과가 반영된다.
- 역 일기 섹션이 투표 완료 후 노출된다.
- 댓글에 이미지/GIF URL 첨부가 가능하고 조회 시 렌더링된다.
- 예외정책
- 즐겨찾기 역이 없으면 “즐겨찾기 역 설정 유도” 상태로 대체한다.
- 라벨이 없으면 출근/퇴근을 기본 주 투표로 사용한다.
- 이미지 URL 파싱 실패 항목은 저장에서 제외하고 사용자에게 경고한다.
