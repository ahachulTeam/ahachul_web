# PM -> FE/BE 핸드오프: 댓글 스레드 프로덕션 고도화 (2026-02-25)

## 1. 구현 목표

- 댓글/답글/비밀댓글 기능을 유지하면서 댓글 좋아요와 정렬(최신/인기)을 제품 수준으로 고도화한다.
- one-app과 Vite 모두 동일한 UX/정책을 갖게 한다.

## 2. FE 전달 사항

### 필수

- 댓글 섹션 정렬 탭 추가: `최신순(createdAt,desc)`, `인기순(likes,desc)`
- 댓글 카드에 좋아요 버튼/카운트/활성 상태(`likedByMe`) 노출
- 좋아요 토글 후 목록 재조회
- 비밀댓글/답글 정책 회귀 금지

### UX 기준

- 탭은 댓글 헤더 우측 배치
- 선택 상태가 명확히 보이는 세그먼트 버튼 스타일 적용
- 로딩 중 중복 클릭 방지(disabled)

## 3. BE 전달 사항

### 필수

- 댓글 조회 기본 정렬을 최신순으로 변경
- 댓글 조회 응답 필드에 `likedByMe` 추가
- 인기순 정렬에서도 부모-자식 매핑 안정성 보장
- 기존 댓글 좋아요 API 재사용:
  - `POST /v1/comments/{commentId}/likes`
  - `DELETE /v1/comments/{commentId}/likes`

### 품질 기준

- 로그인 사용자 기준 `likedByMe` 정확성 보장
- 비로그인 요청은 `likedByMe=false`
- 정렬 변경에 따른 대댓글 누락/유실 없음

## 4. QA 체크 포인트

- 최신순/인기순 전환 시 목록 순서가 즉시 반영되는지
- 좋아요 등록/해제 시 카운트 및 버튼 상태가 일치하는지
- 비밀댓글 노출 정책(작성자/게시글 작성자/제3자) 회귀 없는지
- 부모 댓글보다 좋아요 많은 대댓글이 있어도 대댓글이 사라지지 않는지
