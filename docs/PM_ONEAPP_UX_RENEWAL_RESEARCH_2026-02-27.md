# one-app UX 리뉴얼 리서치/적용 노트 (2026-02-27)

## 1. 미흡한 부분

- 홈에서 정보 밀도가 높고 실행 버튼이 섞여 있어, 사용자가 어디서 행동을 시작해야 하는지 모호했다.
- 게시판(커뮤니티/유실물/민원)에서 검색/필터/리스트/오류 상태의 시각 위계가 약해 스캔 속도가 떨어졌다.
- 로그인 화면은 브랜드 전달과 행동 유도(왜 로그인해야 하는지)의 설명력이 낮았다.
- 전역 레이아웃(헤더/하단 네비/배경)이 기능마다 분절되어 제품 톤이 일정하지 않았다.

## 2. 개선 포인트

- IA를 `홈(요약) -> 허브(행동 선택) -> 상세(집중 작업)` 3단으로 재구성한다.
- 액션 빈도가 높은 기능을 “빠른 실행” 블록으로 묶고, 2-depth 진입을 기본 UX로 고정한다.
- 목록형 화면은 동일한 카드 규칙(검색 -> 필터 -> 컨텐츠 카드 -> FAB)을 강제해 예측 가능성을 높인다.
- 전역 배경/카드/모션 규칙을 통일해 페이지 전환 시 인지 부하를 줄인다.

## 3. 웹 리서치 근거

- Android Navigation 원칙: 목적지 구조를 단순화하고 예측 가능한 진입 흐름 유지
  - https://developer.android.com/guide/navigation/principles
- Baymard 필터 UX 연구: 필터 제어는 “탐색을 방해하지 않는 구조”가 전환율에 유리
  - https://baymard.com/blog/allow-applying-of-multiple-filter-values
- 입력 반응성(INP): 상호작용 반응속도는 체감 UX에 직접 영향
  - https://web.dev/articles/inp
- 접근성 준수 기준(WCAG 2.2): 상태/대비/명확한 조작 가능성 보장 필요
  - https://www.w3.org/TR/WCAG22/

## 4. 개발 진행 (one-app 적용)

- 홈을 `HomeViteParity`에서 `HomeRenewal`로 교체
  - 기능 전체를 클러스터형 허브로 재배치
  - 빠른 실행/경로 매칭/핵심 기능 지도 추가
- 전역 시각 시스템 조정
  - 배경 그라데이션, 글래스 카드, 공통 모션 유틸 추가
- 헤더 리뉴얼
  - 상단 고정 글래스 헤더 + 메시지/알림/마이 바로가기
- 하단 네비 리뉴얼
  - 도크형 내비게이션으로 구조 변경, active 상태 대비 강화
- 로그인 화면 리뉴얼
  - 브랜드 소개 + 가치 제안 + 로그인 액션 카드 구조로 전환
- 게시판 공통 UX 리뉴얼
  - 검색/필터 컨트롤 스타일 통일
  - 게시글 카드 시각 위계 개선
  - 오류/빈 상태 컴포넌트 톤 일관화

## 5. 검증 결과

- 코드 레벨: 홈/헤더/네비/로그인/게시판 공통 컴포넌트가 신규 규칙으로 반영됨
- 품질 게이트: `nextjs:type`, `nextjs:lint`, `nextjs:test` 실행으로 회귀 확인 필요
- 리스크:
  - 홈 데이터 구성은 리뉴얼 과정에서 요약 중심으로 재배치되어, 기존 “홈 직접 실행” 플로우와 동선이 달라질 수 있음
  - 다국어 문구는 기존 번역 리소스 범위를 벗어난 신규 카피가 있어 후속 i18n 정리가 필요함
