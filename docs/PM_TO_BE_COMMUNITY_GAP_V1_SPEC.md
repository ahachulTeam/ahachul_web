# PM -> BE 기능명세 전달서 (커뮤니티 댓글 개선 V1)

- 작성일: 2026-02-24
- 담당 팀: BE
- Task ID: `RF-1100-BE`
- 원문 기준: `docs/PM_COMMUNITY_PAGE_GAP_IMPROVEMENT_SPEC_2026-02-24.md`

## 0. 목표

- 커뮤니티 댓글의 `수정/삭제` API 계약을 명확히 추가하고, FE가 즉시 연동 가능한 안정적 응답/에러 규칙을 제공한다.
- 권한/검증/존재하지 않는 리소스 처리를 명시적 코드로 고정한다.

## 1. 구현 범위 (P0)

1. 댓글 수정 API 추가

- `PATCH /v1/community-posts/{postId}/comments/{commentId}`

2. 댓글 삭제 API 추가

- `DELETE /v1/community-posts/{postId}/comments/{commentId}`

3. 작성자 본인 권한 검증
4. 소프트 삭제 정책 정합성 확보(삭제 후 FE 렌더 가능 데이터 제공)

## 2. 구현 범위 (P1)

1. 댓글 생성/수정 입력 검증 강화(길이/금칙어)
2. 예외 응답 표준화(에러 코드 + 메시지)
3. 댓글 목록 조회 응답에 삭제 상태 표현 필드 보강(필요 시)

## 3. 필수 에러 정책

1. `403` 권한 없음
2. `404` 댓글 없음
3. `400` 검증 실패

## 4. BE 체크리스트

1. API 문서/스웨거 반영
2. 서비스/리포지토리 단위 테스트 추가
3. 컨트롤러 통합 테스트 추가
4. FE 연동용 샘플 응답(JSON) 제공

## 5. 데이터/도메인 정책

1. 삭제는 하드 삭제가 아닌 소프트 삭제 우선
2. 삭제 댓글은 본문 비노출 처리 가능해야 함
3. 수정 시 수정 시각/수정 여부 추적 가능해야 함

## 6. 완료 기준 (DoD)

1. PATCH/DELETE API 정상/예외 케이스 테스트 통과
2. 권한 우회 불가
3. FE 계약 테스트(JSON 고정 샘플) 통과
4. 배포 후 기존 댓글 조회/작성 동작 회귀 없음

## 7. BE 산출물

1. 구현 커밋 + 테스트 로그
2. API 계약 문서(요청/응답/에러)
3. FE 공유용 예외 케이스 표
