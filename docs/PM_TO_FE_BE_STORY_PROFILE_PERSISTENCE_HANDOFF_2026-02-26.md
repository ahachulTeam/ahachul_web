# PM -> FE/BE 핸드오프: 프로필 고정형 스토리

## 1. 미흡한 부분

- 사진 중심의 즉시 공유 UI가 부족해 사용자 체류 경험이 약했다.
- 프로필에서 시각적 기록(스토리 아카이브) 노출이 제한적이었다.

## 2. 개선 포인트

- 인스타그램형 스토리 스트립/풀뷰어 UX를 도입한다.
- 스토리는 휘발 UI로 소비되지만 데이터는 프로필에 계속 남긴다.
- 사용자 삭제 시 즉시 비노출 처리한다.

## 3. 개발 진행 요청

### FE

- Vite
  - 마이페이지에 스토리 업로드/목록/뷰어/삭제 구현
  - 유저 프로필에 스토리 스트립/뷰어 연결
- one-app
  - 마이페이지에 스토리 업로드/목록/뷰어/삭제 구현
  - 유저 프로필(`user/[username]`)에 스토리 스트립/뷰어 연결
- 공통
  - 업로드 오류(이미지 누락/파일 오류/서버 오류) 인라인 메시지 처리
  - 조회 실패/비공개/빈 상태 문구 분리

### BE

- Story API 안정화
  - 작성/조회/삭제 권한 검증
  - 이미지/캡션 검증
  - 프로필 공개 정책 연동(`asPublic`)
- Docs 테스트 및 문서 동기화

## 4. 검증 체크리스트

- 업로드 후 즉시 목록 반영되는가
- 삭제 후 즉시 목록/프로필에서 사라지는가
- 타인 프로필에서 공개 정책대로만 노출되는가
- FE type/lint/test, BE docs test가 통과하는가
